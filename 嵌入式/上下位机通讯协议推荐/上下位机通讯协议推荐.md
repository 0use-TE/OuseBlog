# 上下位机通讯协议推荐

> 适用：上下位机自定义通讯（WebSocket / TCP / UDP / 串口）

## 一、帧格式

```
req=N,cmd,arg1,arg2,*XX\n
```

| 元素 | 说明 |
|------|------|
| `req=N` | 请求 ID（自增整数，`res` 必须回同一 `id`；可省略） |
| `cmd` | 命令名，小写字母+下划线 |
| `arg` | 整数或浮点（`25.5` 直接传，与分隔符无冲突） |
| `*XX` | XOR 校验（两位大写十六进制），**可选** |
| `\n` | 帧结束符（`0x0A`），**可选** |

字符集：`0-9 a-z , - . = * \n`，大写、空格、其它符号禁用。

### 响应

```
res=N,cmd,ok
res=N,cmd,ok,data          ← 读命令带数据
res=N,cmd,bad_arg          ← 失败
nack                       ← 帧错（不携带 cmd）
```

## 二、传输层配置

| 传输层 | `\n` | `*XX` | 理由 |
|--------|------|-------|------|
| WebSocket | 关 | 关 | 消息自带边界，TCP 内建校验 |
| TCP | 开 | 可选 | 字节流需定界，校验视噪声情况 |
| UDP | 开 | 开 | 易丢包易乱序 |
| 串口 | 开 | 开 | 噪声会改字符 |

## 三、为什么需要 `req`

| 场景 | 需要 `req`？ |
|------|--------------|
| 严格一问一答（等 ack 才能发下一条） | ❌ |
| 并发发命令 / UDP 乱序 / 异步上报 / 多上位机 | ✅ |

> 判据：**存在「发出去但还没收到回复」的多条命令，就需要 `req`。**

## 四、示例

```
A → B: req=1,move,60,120
B → A: res=1,move,ok

A → B: req=2,speed
B → A: res=2,speed,ok,120

A → B: req=3,temp
B → A: res=3,temp,ok,25.5

A → B: hello
B → A: res=0,hello,ok,device=car01
```

## 五、代码示例

### Python

```python
def xor_checksum(s: str) -> int:
    """计算字符串的 XOR 校验"""
    c = 0
    for ch in s:
        c ^= ord(ch)
    return c

def encode(cmd: str, args: list, req: int = 0, with_cs: bool = True) -> str:
    """编码一帧：req=N,cmd,arg1,arg2,*XX"""
    parts = [f"req={req}", cmd] + [str(a) for a in args]
    body = ",".join(parts)
    if with_cs:
        cs = xor_checksum(body)
        return f"{body}*{cs:02X}\n"
    return f"{body}\n"

def decode(frame: str):
    """
    解码一帧，返回 (req, cmd, status, data) 或 None
    status 非空表示这是响应；为空表示这是命令
    """
    frame = frame.strip()
    if not frame:
        return None

    # 分离校验
    body = frame
    if "*" in frame:
        body, cs_str = frame.rsplit("*", 1)
        try:
            cs_recv = int(cs_str, 16)
        except ValueError:
            return None
        if xor_checksum(body) != cs_recv:
            return None  # 校验失败

    parts = body.split(",")
    if not parts or not parts[0]:
        return None

    # 解析 req=N
    req = 0
    offset = 0
    if parts[0].startswith("req="):
        try:
            req = int(parts[0][4:])
        except ValueError:
            return None
        offset = 1

    if offset >= len(parts) or not parts[offset]:
        return None
    cmd = parts[offset]
    rest = parts[offset + 1:]

    # 响应：res=N,cmd,status[,data]
    if cmd == "res" and rest:
        try:
            r = int(rest[0])
            rest = rest[1:]
        except ValueError:
            r = req
        if not rest:
            return None
        return (r, rest[0], rest[1] if len(rest) > 1 else "", rest[2] if len(rest) > 2 else "")

    if cmd == "nack":
        return (0, "", "nack", "")

    # 命令
    return (req, cmd, "", rest)


# ---- 使用示例 ----
# 上位机发送
frame = encode("move", [60, 120], req=1)
print(f"发送: {frame.strip()}")

# 下位机响应
resp = encode("res", [1, "move", "ok"])
print(f"响应: {resp.strip()}")

# 读温度（带浮点）
recv = encode("res", [3, "temp", "ok", "25.5"])
result = decode(recv)
print(f"收到: {result}")
```

### C#（WebSocket / TCP / UDP / 串口通用）

```csharp
using System;
using System.Collections.Generic;
using System.Text;

public class Protocol
{
    /// <summary>计算 XOR 校验</summary>
    public static byte XorChecksum(string s)
    {
        byte c = 0;
        foreach (var ch in s) c ^= (byte)ch;
        return c;
    }

    /// <summary>编码一帧</summary>
    public static string Encode(string cmd, IList<string> args, int req = 0, bool withCs = true)
    {
        var sb = new StringBuilder();
        sb.Append($"req={req},{cmd}");
        foreach (var a in args) sb.Append(",").Append(a);
        var body = sb.ToString();
        return withCs ? $"{body}*{XorChecksum(body):X2}\n" : $"{body}\n";
    }

    /// <summary>
    /// 解码一帧，返回 (req, cmd, status, data)
    /// 校验失败返回 null
    /// </summary>
    public static (int req, string cmd, string status, string data)? Decode(string frame)
    {
        frame = frame.Trim();
        if (string.IsNullOrEmpty(frame)) return null;

        string body = frame;
        if (frame.Contains("*"))
        {
            var idx = frame.LastIndexOf('*');
            body = frame.Substring(0, idx);
            var csStr = frame.Substring(idx + 1);
            if (!byte.TryParse(csStr, System.Globalization.NumberStyles.HexNumber, null, out var csRecv))
                return null;
            if (XorChecksum(body) != csRecv) return null;
        }

        var parts = body.Split(',');
        if (parts.Length == 0 || string.IsNullOrEmpty(parts[0])) return null;

        int req = 0, offset = 0;
        if (parts[0].StartsWith("req="))
        {
            if (!int.TryParse(parts[0].Substring(4), out req)) return null;
            offset = 1;
        }

        if (offset >= parts.Length || string.IsNullOrEmpty(parts[offset])) return null;
        var cmd = parts[offset];

        // 响应：res=N,cmd,status[,data]
        if (cmd == "res" && offset + 1 < parts.Length)
        {
            int r = req, ro = 0;
            if (int.TryParse(parts[offset + 1], out var rid)) { r = rid; ro = 1; }
            int baseIdx = offset + 1 + ro;
            if (baseIdx >= parts.Length) return null;
            return (r, parts[baseIdx],
                baseIdx + 1 < parts.Length ? parts[baseIdx + 1] : "",
                baseIdx + 2 < parts.Length ? parts[baseIdx + 2] : "");
        }
        if (cmd == "nack") return (0, "", "nack", "");

        // 命令
        var argsList = new List<string>();
        for (int i = offset + 1; i < parts.Length; i++) argsList.Add(parts[i]);
        return (req, cmd, "", string.Join(",", argsList));
    }
}

// ---- 使用示例 ----
class Program
{
    static void Main()
    {
        var send = Protocol.Encode("move", new[] { "60", "120" }, req: 1);
        Console.WriteLine($"发送: {send.Trim()}");

        var recv = Protocol.Encode("res", new[] { "1", "move", "ok" });
        var result = Protocol.Decode(recv);
        Console.WriteLine($"收到: req={result?.req}, cmd={result?.cmd}, status={result?.status}");
    }
}
```

**使用注意：**
- `*XX` 与 `\n` 均可关：在 `Encode` / `Decode` 里跳过对应步骤即可
- WebSocket 一帧 = 一条消息，无需额外切分
- TCP/串口要按 `\n` 切分累积缓冲区
- UDP 同 TCP，但不阻塞等响应，超时即视为丢包
